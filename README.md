# SmartMove Transport Solutions — Data Management System

Welcome to the central repository for **SmartMove Transport Solutions**. This project is a hybrid database application designed for a transportation service provider to manage vehicles, driver assignments, route planning, trip scheduling, ticket reservations, payment processing, and unstructured multimedia feedback.
