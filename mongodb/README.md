# SmartMove Transport Solutions - MongoDB

Member 3 owns this folder.

MongoDB stores dynamic and unstructured transportation data:
1. Vehicle images and documents
2. Passenger reviews and feedback
3. Travel announcements and notifications
4. Trip-related multimedia

IDs used include vehicleId, passengerId, tripId, routeId, and driverId.

## Run order
1. create_collections.js
2. insert_data.js
3. queries.js
4. updates.js
5. aggregation.js

Run with MongoDB Compass or mongosh. Database: `smartmove_transport`.

## Required coursework queries
1. Reviews for a specific route
2. Highest-rated vehicles
3. Highest-rated drivers
4. Keyword search through customer feedback
5. Vehicle documents and multimedia retrieval

Oracle handles relational operational data. MongoDB handles dynamic/unstructured data. This folder contains only the Member 3 MongoDB implementation.
